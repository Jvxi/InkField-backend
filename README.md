## ⚡ 快速开始

<div align="center">

[![JDK](https://img.shields.io/badge/JDK-21-ED8B00?style=for-the-badge&logo=openjdk&logoColor=white)](https://openjdk.org/)
[![Maven](https://img.shields.io/badge/Maven-3.9+-C71A36?style=for-the-badge&logo=apachemaven&logoColor=white)](https://maven.apache.org/)
[![PostgreSQL](https://img.shields.io/badge/PostgreSQL-15+-4169E1?style=for-the-badge&logo=postgresql&logoColor=white)](https://www.postgresql.org/)

</div>

### 1️⃣ 克隆项目

```bash
git clone https://github.com/Jvxi/InkField-backend.git
cd InkField-backend
```

### 2️⃣ 配置数据库

创建 PostgreSQL 数据库：

```sql
CREATE DATABASE inkfield;
```

修改 `src/main/resources/application.yml`：

```yaml
spring:
  datasource:
    url: jdbc:postgresql://localhost:5432/inkfield
    username: your_username
    password: your_password
```

### 3️⃣ 运行项目

```bash
mvn spring-boot:run
```

<div align="center">

🎉 API 地址：**http://localhost:4000/api**

</div>

### 4️⃣ 构建打包

```bash
mvn clean package
```

构建产物在 `target/` 目录下。

## 🌟 API 接口

<details>
<summary><b>🔐 认证接口 (/api/auth)</b></summary>

<br/>

| 方法 | 路径 | 说明 |
|:---:|:---|:---|
| POST | `/register` | 用户注册 |
| POST | `/login` | 用户登录 |
| POST | `/logout` | 用户登出 |
| GET | `/me` | 获取当前用户信息 |

</details>

<details>
<summary><b>📁 项目接口 (/api/projects)</b></summary>

<br/>

| 方法 | 路径 | 说明 |
|:---:|:---|:---|
| GET | `/` | 获取项目列表 |
| POST | `/` | 创建项目 |
| GET | `/{id}` | 获取项目详情 |
| PUT | `/{id}` | 更新项目 |
| DELETE | `/{id}` | 删除项目 |

</details>

<details>
<summary><b>🤖 AI 生成接口 (/api/generation)</b></summary>

<br/>

| 方法 | 路径 | 说明 |
|:---:|:---|:---|
| POST | `/outline` | 生成大纲 |
| POST | `/chapter` | 生成章节（流式） |
| POST | `/characters` | 生成角色建议 |

</details>

<details>
<summary><b>✅ 合规校验接口 (/api/compliance)</b></summary>

<br/>

| 方法 | 路径 | 说明 |
|:---:|:---|:---|
| POST | `/check` | 校验章节合规性 |
| GET | `/report/{chapterId}` | 获取合规报告 |

</details>

## 🗄️ 数据库设计

<div align="center">

使用 **Flyway** 进行数据库版本管理，迁移脚本位于 `src/main/resources/db/migration/`

</div>

| 版本 | 文件 | 说明 |
|:---:|:---|:---|
| V1 | `V1__init_schema.sql` | 初始化用户表 |
| V2 | `V2__add_story_system_tables.sql` | 故事系统表 |
| V3 | `V3__add_memory_tables.sql` | 记忆系统表 |
| V4 | `V4__add_rag_tables.sql` | RAG 相关表 |
| V5 | `V5__add_reading_power_tables.sql` | 阅读力表 |
| V6 | `V6__add_commit_event_tables.sql` | 提交事件表 |
